# Contributing Guidelines

## Team Collaboration Workflow
This project is managed collaboratively by Group12 using GitLab and Taiga.

### Git Commands
Clone the repository:
```bash
git clone https://github.com/kayaleyyna/chatbot-birdsbot.git
```

Create a new branch:
```bash
git checkout -b feature/add-intents
```

Add and commit changes:
```bash
git add .
git commit -m "Added new intents and updated README"
```

Push your branch:
```bash
git push origin feature/add-intents
```

After reviewing, create a **Merge Request (MR)** and link it to the related **Taiga User Story**.

### Coding Standards
- Use clear variable and function names.  
- Include docstrings for every function.  
- Write meaningful commit messages.  
- Avoid pushing directly to the main branch.  

### Documentation
Update documentation (README or USAGE) whenever functionality changes.
